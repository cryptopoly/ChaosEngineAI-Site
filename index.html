Speculative decoding

Faster code and reasoning. Same output.

The model drafts several tokens ahead and checks them in one pass. The reply is the same as plain decoding, only faster. The backend picks the best path for each model.

  • MTPLX — uses the model's own Multi-Token Prediction heads (Qwen3.5/3.6, DeepSeek V3/R1, Qwen3-Coder-Next). 1.8–2.2x on Apple Silicon.
  • DFlash — a small draft model proposes, the target verifies. Qwen3-4B: about 53 to 113 tokens per second.
  • DDTree — drafts a tree of candidates and keeps the longest correct branch. Hybrid models such as Qwen3.5/3.6 use linear DFlash.
  • Fallback — MTPLX falls back to DFlash, DFlash to standard generation.
  • Note — creative writing can run slower. Leave it off for stories.

Cache strategies

Fit longer chats. Render faster.

Pick a cache strategy from the app, not a shell flag. Install an optional backend, restart, and it appears in the picker.

  • Native f16 — full precision, always available
  • TurboQuant — a much smaller KV cache for long chats. A memory saver: generation is slower.
  • TriAttention — KV cache compression inside vLLM, on Linux + CUDA
  • FBCache, TeaCache, TaylorSeer, PAB — skip repeated work in image and video models. FBCache: about 1.8x on FLUX.1-dev.
  • MagCache, FasterCache — through chaosengine-cli and the local API

  "model": "current-model",
  "apiBase": "http://127.0.0.1:8876/v1"

chaosengine-cli drives the whole backend.

A typed CLI that reaches every backend route. Script chat, image, video, benchmarks, setup, and diagnostics.

Full-surface coverage

Typed shortcuts for load, prompt, bench, image, video, server, setup, and diagnostics. Generic call <METHOD> <PATH> reaches every other backend route.

Composable output

Python stdlib only. JSON to stdout, composes with jq and CI jobs. Streaming and non-streaming modes with optional inline metrics.

chaosengine-cli load mlx-community/Qwen3.6-35B-A3B-4bit --spec
chaosengine-cli prompt "Write a Rust quicksort" --stream --metrics
chaosengine-cli video-generate "Aurora over a glacier, drone shot" --model Wan-AI/Wan2.1-T2V-1.3B
