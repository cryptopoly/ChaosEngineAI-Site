Why it feels different

ChaosEngineAI is not just another launcher.

It behaves like a proper local control plane: the model catalog, runtime tuning, tool calling, image pipeline, server surface, benchmark rig, prompt library, and plugin system all live in one coherent workspace.

One place for runtime decisions

Decide between native f16, compressed KV caches, or speculative decoding without dropping to shell scripts or juggling manual flags.

One place for proof

Run a benchmark, save the result, diff it later, and answer whether a new cache strategy or draft model is actually worth it.

One place for outputs

Threads, image generations, prompt templates, logs, adapters, and API integration snippets all stay inside the same desktop surface.

    ChaosEngineAI blends local inference, agent tooling, image workflows, evaluation, and developer integrations into one product surface.

    Native MTP speculative decoding

    1.8–2.2x faster generation with zero quality loss.

    • Native Multi-Token Prediction on Apple Silicon, no separate draft model required.
    • Backed by mtplx (Apache 2.0) running in an isolated venv so it cannot drift the main runtime.
    • Supported families include Qwen3.5, Qwen3.6, Qwen3-Coder-Next, DeepSeek V3/R1, and Youssofal MTPLX-Optimized variants.
    • One-click install from the Setup tab; auto-detected and offered when the loaded model can use it.
    • Graceful fallback to native generation when MTP is unavailable for the chosen model.

    Headless automation

    chaosengine-cli drives the whole backend from the terminal.

    A typed CLI wrapper that reaches every backend endpoint. Script chat, image generation, video, benchmarks, setup, and diagnostics without opening the desktop app.

    Full-surface coverage

    95 ergonomic shortcuts plus a generic dispatcher.

    • 95 typed shortcuts for the common paths: load, prompt, bench, image, video, server, setup.
    • Generic call <METHOD> <PATH> reaches the remaining backend routes — 100% of the 125 endpoints.
    • Python stdlib only. No extra dependencies, no virtualenv needed for the CLI itself.
    • JSON to stdout by default so it composes cleanly with jq, shell pipelines, and CI jobs.
    • Streaming and non-streaming generation modes with optional inline metrics.
    Quick start 
    chaosengine-cli load Youssofal/Qwen3.6-27B-MTPLX-Optimized-Speed --spec
chaosengine-cli prompt "Write a Rust quicksort" --stream --metrics
chaosengine-cli bench mlx-community/Qwen3.6-35B-A3B-4bit --runs 3
