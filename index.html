    Feature spread

    Broader than a launcher. Tighter than a notebook.

    Local inference, voice, agent tooling, image and video workflows, evaluation, and developer integrations — one surface.

    Voice

    Talk to your models. Nothing is uploaded.

    • Voice calls in Chat: press Call, talk, and interrupt the model mid-answer. Every turn is saved in the thread.
    • Dictation from the composer, and a speaker button on every reply (or have replies read automatically).
    • Voice Studio: transcribe files or recordings in a queue with speaker labels, translate to English, edit, and export TXT, Markdown, SRT, VTT or JSON.
    • Speak turns long text into speech, saved as WAV or MP3. Voice Library keeps every recording, transcript and clip.
    • Install the voice pack once (about 2 GB). Apple Silicon: Parakeet, Nemotron 3.5 or Whisper, plus Kokoro. Windows and Linux: Whisper and Kokoro, newer and less tested.
    Chat and prompting

    Threads that remember their runtime.

    • Multi-thread chat with pinned sessions and per-thread model + runtime memory.
    • Document uploads with chunked retrieval and inline citations.
    • Vision attachments, reasoning mode, and collapsible thinking traces.
    • Tool calling: web search, calculator, file reader, code executor.
    • Prompt Library with searchable templates, tags, and one-click apply.
    Models and runtimes

    From browsing to serving without leaving the app.

    • One Models page each for Chat, Images and Video, with curated catalogs, Hugging Face browsing, and filters for Installed, Available, Downloading or Needs attention.
    • Best fit for your hardware: every row says Fits, Tight, Won't fit, or Not for this machine, marks estimates as estimates, and each family points at the newest model that fits.
    • Multiple model directories, and Apple Silicon conversion from Hugging Face checkpoints to MLX with live progress.
    • Warm-pool runtime reuse for instant reactivation of recent profiles.
    • OpenAI-compatible local server with LAN mode, auto-start, and live request stats.
    Added in v0.9.9

    New models, ready to run.

    • Nemotron 3.5 Bolt (NVIDIA): a 4B-effective assistant model for voice and device assistants. The official 6 GB build runs on macOS, Windows and Linux; with its DFlash drafter an M4 Max goes from about 62 to about 160 tokens per second.
    • Granite Switch 4.1 (IBM, Apache 2.0): the 8B and 30B Granite models in one checkpoint with built-in decision and safety adapters. The app runs the chat model.
    • LFM3-1.7B (Liquid AI): 256K context, 16 languages, tool calling. About 250 tokens per second on an M4 Max with the official MLX 4-bit build (about 1 GB), plus an official GGUF for every platform.
    • Nemotron 3.5 speech recognition (Apple Silicon): 40 languages with automatic language detection. A 5-second clip takes about 0.14 seconds on an M4 Max once the model is loaded.
    • Iris-3B Turbo on Apple Silicon (Apache 2.0): four steps, a 1024 by 1024 image in about 18 seconds on an M4 Max, using 7.5 GB of memory.
    Image Studio

    A full local image pipeline.

    • Images Models page for curated diffusion models, with fit badges and compatibility-aware installs.
    • "Recommended for this machine": steps, size and other settings with a reason and a Measured or Estimated tag, applied in one click. On an M4 Max, FLUX 3 Klein at 8 steps takes 40 seconds instead of 70 with no visible difference.
    • Bigger images: each model has its own size limit (FLUX.2 and Qwen-Image-2.1 up to 4096) and the memory check counts pixels. On a 64 GB Mac, FLUX 3 Klein made a 3072 by 3072 image in under two minutes; 4096 by 4096 was refused with a size that fits.
    • Aspect ratios, seeds, negatives, and quality presets; a gallery with reruns, seed variation, reveal on disk, and saved metadata so you can reproduce what worked.
    • Preload and unload controls so diffusion behaves like the text runtime. Controls an engine ignores are hidden.
    Video Studio

    Local text-to-video, same workspace.

    • LTX-2.3 and LTX-2.5 on Apple Silicon run on their own MLX engine and write sound with the picture. Clips with sound show a Sound badge in the gallery and play with sound.
    • Measured on an M4 Max: a 4-second 768 by 512 clip takes about 2.5 minutes with LTX-2.3 and 128 seconds with LTX-2.5, which is now the default LTX model.
    • LTX-2.5 is a gated Hugging Face repo: accept its licence on the model page and give your token read access to public gated repos.
    • Wan 2.1 and Wan 2.2 A14B: one-click install downloads the checkpoint and converts it to MLX in the background.
    • Cross-platform fallback via diffusers and stable-diffusion.cpp on CUDA (HunyuanVideo, CogVideoX, Mochi).
    • "Recommended for this machine" settings, cache strategies (FBCache, TeaCache, TaylorSeer, MagCache, PAB, FasterCache), and live per-step thumbnails on diffusers models so you can kill bad seeds early.
    Performance and proof

    Measure the tradeoff. Don't guess.

    • Throughput, perplexity, and task-accuracy benchmarks in the same UI.
    • Persistent history with chart and table views, delta tables, scatter plots.
    • DFlash and DDTree speculative decoding on Apple Silicon with draft-model auto-resolution. On a 30B-class 4-bit model, code and reasoning replies run 1.4 to 1.7 times faster; creative writing can run slower, so leave it off for stories.
    • Runtime controls for cache bits, FP16 layers, context, fused attention.
    • Live telemetry, backend health, logs, and orphaned-worker cleanup.

    Headless automation

    chaosengine-cli drives the whole backend.

    A typed CLI that reaches every backend route. Script chat, image, video, benchmarks, setup, and diagnostics.

    Full-surface coverage

    Typed shortcuts plus a generic dispatcher.

    • Typed shortcuts for load, prompt, bench, image, video, server, setup, and diagnostics.
    • Generic call <METHOD> <PATH> reaches every other backend route.
    • Python stdlib only. No extra dependencies.
    • JSON to stdout — composes cleanly with jq and CI jobs.
    • Streaming and non-streaming modes with optional inline metrics.
    Quick start 
    chaosengine-cli load mlx-community/Qwen3.6-35B-A3B-4bit --spec
chaosengine-cli prompt "Write a Rust quicksort" --stream --metrics
chaosengine-cli video-generate "Aurora over a glacier, drone shot" --model Wan-AI/Wan2.1-T2V-1.3B
